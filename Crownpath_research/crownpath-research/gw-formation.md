## Guild War team shape

| Layer | Count |
| --- | --- |
| Heroes per round | **3** |
| Rounds per attack / defense package | **2** (Round 1 + Round 2) |
| Defense packages per player | **1** building assignment, but **two** 3-hero comps (R1 / R2) |

Attack also builds **2 rounds × 3 heroes**.

## GW battlefield (3 heroes) — attacker view

Camera: **your offense left (green)**; **enemy defense right (red)**.

Enemy cluster is a **triangle / diamond-like** layout, **not** a flat 3-across bar.

Diagram — **enemy defense** as the attacker sees it (right side of screen):

```text
        [Rear]        [Rear]
              [Front]
           ↑ lower apex = foremost
```

| Visual (attacker cam, enemy side) | Position name |
| --- | --- |
| Lower apex (closest toward center / toward you) | **Front** / foremost / leader |
| Upper-left node of that enemy cluster | Rear |
| Upper-right node of that enemy cluster | Rear |

Do **not** call Front “the rightmost portrait” on the fight screen. Foremost = the **Front seat**, per skill wording (e.g. Proof of Friendship “foremost ally”).

## Arena / standard field (4 heroes)

Arena uses **4** nodes (diamond-style Front / Mid×2 / Back). Visible geometry **differs** from GW’s **3**-node triangle.

| Slot name | Count |
| --- | --- |
| Front (Front Row / foremost) | 1 |
| Middle | 2 |
| Back (Back Row) | 1 |

Turn order / Combat Readiness order is **Speed**, not slot.

## Guild War Q block (asked)

**3 slot defense, dari mata attacker: kiri–kanan, depan–belakang?**  
Dari mata attacker: musuh di **kanan** layar. Bentuk **segitiga**: **depan** = apex bawah (Front); **belakang** = dua node atas (kiri/kanan relatif viewer).

**Slot mana Front / foremost ally (yang kanan di arena kita)?**  
Front = **foremost / leader seat** (apex depan di fight). Itu **bukan** otomatis “hero paling kanan di layar fight.” Klaim Arena “kanan di Team screen” = **Unsure** di file ini sampai ada shot ber-label.

**Ada diamond / baris / lain?**  
GW fight: **triangle** (2 rear + 1 front). Arena 4: **diamond** 4 node. Bukan baris horizontal 3.

**Gambar atau tabel: slot 1, 2, 3 + nama posisi.**  
Lihat tabel visual di atas. **Tidak** ada ID angka 1/2/3 yang terverifikasi sumber.

**Sama atau beda dengan arena 4 orang?**  
**Beda** geometri tampilan (3 vs 4). **Sama** arti **foremost ally** = kursi Front.
