Scope: **regular Arena defense** patterns hit in high ranks. Check the **8 named plans** below. Do not invent a 9th name. No scout recipes. No meta bible.

Keywords locked: **Combat Readiness** (not turn bar). **Extra Attack** is not **Dual Attack**. **Seal** is not **Cannot Buff**. **CR cut** is not a **Speed cap**. Harsetti’s PvP limit is a **Speed cap** (90% of her Speed).

## The 8 plans (cek — jangan usul kode baru)

| Code | Plan idea (one line) |
| --- | --- |
| `speed-cleave` | Outspeed / first-cycle wipe |
| `harsetti-stall` | Harsetti Speed lock + CR-increase block; fight goes slow |
| `revive-wall` | Revive / second life is the fail condition |
| `injury-grind` | Injury snowball over turns |
| `evasion-counter` | Miss / evade + counter / extra-attack pressure |
| `turn2-control` | Reset / rat / turn-2 mess (not pure race) |
| `immunity-soul` | Imm open + Soul denial (Belian-class) |
| `bruiser-mix` | Bulk DPS / reflect / egg pressure without one of the above as the core |

If a wall fits **none**, say why it is a **different plan**, not just a unique Watch.

## How to read

- **Plan tags** (race / stall / reset / injury / miss / lock / soul lock / mix) = what the attacker feels.
- **Map** = one of the 8 codes, or `none`.
- Samples are dated. Oct 2025 Champion+ is still useful; April 2026 tip is the freshest “current Arena def meta” line found.

## Patterns (8)

### 1. Harsetti lock + BBK cleave threat

| | |
| --- | --- |
| **4 examples** | Harsetti / Blood Blade Karin / Lady of the Scales / Setsuka |
| **Plan tags** | lock + miss + mix |
| **Map** | `harsetti-stall` |
| **Sample** | tehvidya **2025-10**, Champion→Emperor Arena (Enemy Team 4) |

Harsetti caps Speed and blocks Combat Readiness **increase** on her turn. Setsuka adds miss / counter threat. LotS raises ER / sustain pressure. Not a Speed race into cleave.

### 2. Genesis Ras absorb + LotS + Setsuka + Frieren

| | |
| --- | --- |
| **4 examples** | Genesis Ras / Lady of the Scales / Setsuka / Frieren |
| **Plan tags** | miss + stall + mix |
| **Map** | `evasion-counter` |
| **Sample** | tehvidya **2025-10**, Champion→Emperor (Enemy Team 3; also Team 2 variant with Harsetti) |

Setsuka / Frieren punish attacks with evade, counter, and extra-attack loops. GRas absorb phase forces a long fight. Roana-class answers appear because of **extra attack / counter**, not Dual Attack unless the skill says Dual Attack.

Variant with Harsetti instead of Frieren still maps primarily to `harsetti-stall` when Harsetti is present (Team 2).

### 7. Notos + Perfumer Byblis core (2026 Arena)

| | |
| --- | --- |
