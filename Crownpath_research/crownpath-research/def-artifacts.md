## How to read

| Tag | Meaning |

## Staples that matter on defense

### Holy Sacrifice (Knight)

| | |
| --- | --- |
| **Wears** | Notos (Fribbels ~75% rec), also Abyssal Yufine / Mort / Empyrean Ilynav / Genesis Ras / Dragon Bride Senya / Belian niche |
| **Does** | On death: chance to revive at 25% HP + barrier (max HP scaling). **Once.** Max enhance = 100% revive chance |
| **Does not** | Prevent Extinction / anti-revive; does not Soulburn; does not stop Seal / Unable to be buffed on the revive turn by itself |
| **Wall vs Watch** | **Wall note** — plan for a second life + barrier |

### Elbris Ritual Sword (Knight)

| | |
| --- | --- |
| **Wears** | Belian (Fribbels ~42%), Abyssal Yufine (~67%), Empyrean Ilynav, Charles-line, Genesis Ras (tip-cited) |
| **Does** | When an **ally except wearer** is attacked: chance to **counterattack** (max 20%) |
| **Does not** | Counter when the wearer is the only one hit; does not grant Dual Attack (counter ≠ Dual Attack); AI still no Soulburn |
| **Wall vs Watch** | **Watch** (can become Wall note if S1 is strip/Injury/CR — threat is the **proc**, not a new archetype name) |

### Proof of Valor (Common)

| | |
| --- | --- |
| **Wears** | Bruisers / tanks (Harsetti, Boss Arunka, Urban Shadow Choux, Notos niche, many HP scalers on epic7db list) |
| **Does** | Damage taken down (max open 30%, decays per hit suffered to floor 15%). **Only one** Valor effect per party. Strongest mitigation wins if stacked with others |
| **Does not** | Stop true percent HP skills by renaming them; does not revive; does not change AI skill order |
| **Wall vs Watch** | **Watch** — budget for more hits, not a new wall type |

### Portrait of the Saviors (Common)

| | |
| --- | --- |
| **Wears** | Offense cleavers (epic7db / Game8). Rarely a “defense identity” art |
| **Does** | +damage if target HP ≥ 50% on attack (max 20%) |
| **Does not** | Add mitigation, revive, or counter |
| **Wall vs Watch** | **Skip / flavor on defense** — if seen, **Watch** only (“hits healthier targets harder”) |

### Sword of Judgment (Ranger)

| | |
| --- | --- |
| **Wears** | Rangers with impactful S1 (Lidica-line, Schuri-line, etc. on epic7db) |
| **Does** | After a **Single Attack**, if target lives: chance to attack again with **basic skill** (once/turn; max 20%) |
| **Does not** | Dual Attack keyword; does not fire on AoE; AI still no Soulburn |
| **Wall vs Watch** | **Watch** — budget an extra S1 |

### Magaraha’s Tome (Soul Weaver)

| | |
| --- | --- |
| **Wears** | Soul Weavers who cast non-attacks (Angelica, Diene, Elena, Emilia, …) |
| **Does** | After a **non-attack** skill: +Combat Readiness (max 30%) |
| **Does not** | Push allies; does not equal a Speed cap; does not create Souls for AI Soulburn |
| **Wall vs Watch** | **Watch** — faster cycle on heal/buff bots |

### Rhianna & Luciella (Thief)

| | |
| --- | --- |
| **Wears** | Thieves (Rinak, Peira, Ran-line, etc. on epic7db) |
| **Does** | +10% Attack; chance for an **extra turn** at end of turn (max 20%, once/turn) |
| **Does not** | Guarantee the extra turn; extra turn ≠ Dual Attack |
| **Wall vs Watch** | **Watch** (high impact RNG) — can feel like Wall note if the thief’s turn wins the fight |

### Aurius (Knight)

| | |
| --- | --- |
| **Wears** | Front Knights (Fallen Cecilia-line, Arowell, Ilynav, Belian niche, …) |
| **Does** | +10% Defense all allies; wearer takes a share of allies’ damage (max 20% share). One Aurius name; strongest distribute wins |
| **Does not** | Cap Damage Share with Valor automatically (separate rules); does not revive |
| **Wall vs Watch** | **Wall note** — kill order / cleave math changes because damage is redistributed |

### Knowledge Seed (Mage)

| | |
| --- | --- |
| **Wears** | Mages on bait / strip lines (Harsetti cited in Asia tip; Angel of Light Angelica, Basar-line on epic7db) |
| **Does** | On lethal damage to wearer: chance to grant **other allies** a random buff for 2 turns (Attack Greater / Defense / Evasion / Immunity / Crit Resist). Once/battle; max 100% |
| **Does not** | Revive the wearer; buff list is random |
| **Wall vs Watch** | **Wall note** when the mage is the bait — killing them can buff the rest |

### 3F (Knight — Albedo bardiche)

| | |
| --- | --- |
| **Wears** | Belian (Fribbels ~41% alongside Elbris), other HP-scaling Knights |
| **Does** | After attacking: chance to deal **additional damage** ∝ caster max HP (max 100% chance) |
| **Does not** | Extra turn; Dual Attack; mitigation |
| **Wall vs Watch** | **Watch** — every hit can chunk harder on fat Knights |
